## Descripción del proyecto
Pequeña sala de entrenamiento XR desarrollada en Unity para evaluar la configuración de entornos virtuales, físicas y manipulación de objetos en realidad extendida.

## Funcionalidades implementadas
* Escenario 3D con límites físicos e iluminación.
* Manipulación de objetos mediante XR Grab Interactable.
* Interacción a distancia mediante Ray Interactor y UI espacial (botón de encendido/apagado de luz).
* Reto libre: Teletransporte mediante Teleportation Area.

## Controles e instrucciones
* Usar los joysticks de los mandos para apuntar y moverse mediante teletransporte.
* Usar el botón de agarre (Grip) para tomar los objetos pequeños.
* Apuntar con el rayo de los mandos al botón del panel y presionar el gatillo (Trigger) para apagar/encender la luz.

## Tecnologías y paquetes utilizados
* Unity 3D (URP)
* XR Plugin Management
* XR Interaction Toolkit
